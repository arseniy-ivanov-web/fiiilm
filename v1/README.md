# FIIILM — прототип

Два разных файла, не путать:

| Что | Файл | Зачем |
|---|---|---|
| **Рабочий прототип** | `index.html` | Настоящее веб-приложение: входишь, у тебя 0 папок, дальше создаёшь и редактируешь всё сам. База для доработки дизайна. |
| **Реплика скриншотов** | `replica.html` | Застывшая копия 38 скриншотов 1:1, включая находки аудита. Нужна как эталон «как было» и как архив. Там же лежат наброски AGGREGATE. |

## Запуск

```bash
python3 -m http.server 4173 --directory prototype
```

Открыть `http://localhost:4173`. Через `file://` не заработает: браузер не отдаёт
соседние css/js и картинки по относительным путям.

## Файлы

| Файл | Что там |
|---|---|
| `index.html` | каркас: рамка телефона, служебная панель, спрайт иконок. Экранов в разметке нет |
| `data.js` | каталог вместо бэкенда: 45 человек, 20 фильмов, связи «кто в каком фильме» |
| `store.js` | состояние и запись в localStorage: папки, ростеры, паккейджинг, заметки, избранное |
| `ui.js` | все экраны, оверлеи и действия. Экраны — функции от состояния |
| `tokens.css` | **точка правки дизайна**: цвета, шрифты, типошкала, отступы |
| `app.css` | компоненты |
| `assets/` | фото и постеры, вырезанные из скриншотов |
| `replica.html` / `replica.js` | реплика скриншотов, отдельная от приложения |

## Как это устроено

Ни один экран не записан в разметку. `ui.js` рисует текущий экран из
`FIIILM_STORE.state`, состояние пишется в `localStorage` и переживает перезагрузку.
Действия помечены в разметке как `data-act="имя"` и разобраны в объекте `ACTIONS` —
новое поведение добавляется туда, а не в обработчики по всему файлу.

Маршруты в хеше: `#folders`, `#folder-new`, `#f/<id>`, `#f/<id>/pack`,
`#f/<id>/add-people`, `#f/<id>/add-movies`, `#search`, `#person/<id>`,
`#movie/<id>/crew|cast`, `#notes/<id>`, `#note/<id>/<noteId>`, `#profile`.

Панель слева — служебная, в приложении её нет: быстрые переходы, список своих папок,
сброс данных и кнопка «Залить пример» (создаёт папку «The Odyssey» с группой фильма
и запущенным паккейджингом, чтобы не кликать всё руками).

## Что работает по-настоящему

- **Вход.** Условный: нажал SIGN IN — и у тебя 0 папок. Кода из письма нет.
- **Папки.** Создание с названием и тегами, поиск по списку, дублирование, удаление.
- **Ростер.** Добавление людей из поиска; добавление фильма целиком — в папку падает
  вся его группа и актёры. Группировка по департаментам, фильтр по департаменту,
  сортировка групп, роли, удаление из папки.
- **Поиск.** Честный по каталогу из `data.js`, отдельно люди и фильмы, со счётчиками.
- **Карточка человека.** Фильмография собирается из каталога, а не прописана руками:
  добавил фильм — он появился в фильмографии всех его участников. Избранное, заметки,
  добавление в папку.
- **Карточка фильма.** Crew и Cast из каталога, фильтр по департаменту.
- **Паккейджинг.** START PACKAGING с переносом ростера, цель с авторостом поля,
  кандидаты, комментарии (диалог Reason), роли, PARK / UNPARK, удаление,
  перетаскивание за ручку со сменой департамента, закрытие и открытие заново
  (в закрытом всё только на чтение). Человек, добавленный в папку во время
  голосования, сам становится кандидатом — как в спеке.
- **Заметки** и **избранное** с фильтром по департаменту в профиле.

Всё это пишется в localStorage. «Сбросить всё» в панели слева возвращает к нулю.

## Чего нет и не будет

- **Приглашений и участников.** Паккейджинг работает на одного — тебя. Поэтому вкладка
  AGGREGATE показывает тост: общий рейтинг и формула `score = avg + (1 − coverage) × 1000`
  без вторых участников считать нечего. Наброски этого экрана лежат в `replica.html`.
- **Сервера.** Нет синхронизации, офлайна с его диалогом, пушей, шеринга по ссылке,
  входа по коду, тарифов.
- **Настоящей базы фильмов.** В приложении поиск идёт по TMDB, здесь — по `data.js`.
  Счётчики считаются по каталогу честно, поэтому «1219» ты не увидишь.
- Вкладки Details карточки фильма, экрана фильтров, правки профиля, удаления аккаунта —
  их не было в скриншотах, и они показывают тост с объяснением.

## Цвета и шрифты

Цвета названы как в твоём DS: `--bg-canvas`, `--text-primary`, `--border-subtle`.
Под ними примитивы `--blue-600` и прочие; `blue/600 = #073DF5` задан тобой, остальные
ступени сняты со скриншотов и правятся в одном месте, в блоке primitives.

Три семейства, как в приложении:

- `--font-pixel` — **подбор, не оригинал.** VT323 с Google Fonts. Кириллицы у него нет,
  поэтому в запасных указан моноширинный: русские названия папок не свалятся в засечки.
  Рядом живут `--pixel-scale` (сейчас 1.25) и `--pixel-weight` — все пиксельные размеры
  записаны как `calc(<размер> * var(--pixel-scale))`, так что смена шрифта не ломает
  вёрстку. Возьмёшь настоящий шрифт приложения — подставь и поставь `--pixel-scale: 1`.
- `--font-mono` — SF Mono, «обычный» текст приложения.
- `--font-sf` — SF Pro для нативных кусков: диалоги, шиты, заметки, клавиатура.

## Допущения

- Каталог выдуман по мотивам реальных фильмов: 45 человек и 20 фильмов. Фото есть только
  у тех, кого удалось вырезать из скриншотов; у остальных голубой плейсхолдер — как
  в самом приложении.
- Фото людей везде квадратные. Это отход от скриншотов, сделан намеренно.
- Экранная клавиатура печатает в сфокусированное поле, но это декорация: настоящий ввод
  идёт с физической клавиатуры.
